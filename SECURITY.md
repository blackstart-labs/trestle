# Security

Trestle is a pre-release development foundation. There are no supported stable
releases or claims of production security. Read the
[initial threat model](docs/threat-model.md) before exposing the server.

Do not disclose vulnerabilities, credentials, private data, or exploit details
in public issues or pull requests. Use GitHub's private vulnerability reporting
feature **if enabled**. If unavailable, establish a private reporting channel
with the maintainer before sharing details; this repository does not yet
publish a dedicated private contact or response SLA.

Include the affected commit, deployment context, a minimal reproduction with
dummy data, and expected versus actual behavior. Redact credentials and tokens.
Do not test against deployments you do not own or have permission to assess.
