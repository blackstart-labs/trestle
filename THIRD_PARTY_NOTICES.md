# Third-party notices

The server binary is built with Go and statically links the Go standard
library and the Go modules listed below (versions from `go.sum`; the set is
what `go list -deps .` reports for the shipped binary). Keep these notices with
binary/container distributions. Regenerate this list from `go.mod`/`go.sum`
and each module's `LICENSE` file whenever dependencies change, and review it
before publishing a release.

The container image also copies the Debian `ca-certificates` bundle
(`/etc/ssl/certs/ca-certificates.crt`, Mozilla CA data under MPL-2.0) from the
Go build image so PostgreSQL TLS verification can use system roots.

and served at `/assets/third-party-licenses.txt`. The initial bundle includes
Svelte 5.57.2 and esm-env 1.2.2 under MIT, with their full upstream notices.
The interface typeface is Mona Sans by GitHub, shipped as WOFF2 files from
`@fontsource-variable/mona-sans` under the SIL Open Font License 1.1; the
license text is in that package's `LICENSE` file and must accompany
redistributed font files. Interface icons are authored inline SVG paths that
follow the Feather/Lucide drawing conventions (MIT/ISC); no icon package is
bundled. Build/test tooling is not shipped in the runtime image. Review this generated
inventory on frontend dependency changes; it does not replace the Go module
notice review described above.
