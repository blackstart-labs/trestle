# Project audit and issue fixes — 2026-11-10

What this repo does: Trestle is a self-hosted workspace for Projects, Tasks, recorded time and knowledge. A Go server serves a Svelte frontend and stores data in PostgreSQL. Assumed load: independent developers and small teams sharing a single instance, including simultaneous edits and phone use.

Branch: `fix/project-audit`. These are local fixes, not published or closed GitHub issues.

## Must fix — implemented

1. **Task links opened the wrong view (#47)** (`web/src/App.svelte`). Startup Workspace selection raced the linked Project, and signed-out arrivals tried loading protected resources. Resolve links after authentication and before rendering the chooser; show retry on resolution errors. Without this, bot links lead users away from the requested Task.
2. **Workspace creation was absent (#38)** (`internal/httpapi/workspaces.go`, `internal/identity/store.go`, `web/src/auth/WorkspaceChooser.svelte`). Neither POST nor a creation form existed. Creation now atomically adds the Workspace, owner membership and audit event. Editing validates the slug, hides database errors, reports conflicts and preserves the caller's role; the form retains drafts and guards navigation.
3. **Creation could not assign people (#36)** (`web/src/projects/TasksView.svelte`, `internal/projects/store.go`). No picker or creation payload existed. Reuse MultiPicker and write assignments in the Task transaction; always show the milestone selector with empty/error guidance. Otherwise people need a second edit and partial requests can leave incomplete Tasks.
4. **Exports silently lost tasks** (`internal/httpapi/export.go`). Passing limit 10,000 to a function capped at 100 returned incomplete backups; several read errors were ignored and archived Projects were omitted. Read every page in a repeatable-read snapshot, reuse one export reader, and fail on any missing data. Otherwise a successful-looking backup cannot restore the Workspace.
5. **Guest roles could mutate Tasks through the API** (`internal/httpapi/projects.go`). Shared scope checks accepted any Workspace member for writes. Deny guest mutations except comments and their existing authorized deletion path; disable task edit controls. Otherwise read-only participants can change shared work.
6. **Timer saves could be duplicated or discarded in flight** (`web/src/lib/timer.svelte.ts`). Multiple timer surfaces could POST the same elapsed time; switching Tasks replaced unlogged time. Share a saving guard, preserve failed timers, and confirm discard/replacement. Otherwise recorded hours can be duplicated or lost.
7. **Integration descriptions exposed markup (#33)** (`internal/httpapi/integrations.go`). Legacy rich-text HTML was escaped into literal visible tags. Convert it to text, skip script/style content, escape provider control syntax, and bound long excerpts. Otherwise notifications are unreadable and long descriptions can exceed provider limits. The saved description is not modified.

## Should fix — implemented

8. **Sticky chrome showed content through text (#51)** (`web/src/App.svelte`). The translucent background let scrolled text interfere with navigation. Use the existing opaque surface token; no new palette or CSP exception.
9. **A project description looked like a counter (#44)** (`web/src/projects/TasksView.svelte`). The screenshot's “1” was stored description content beneath the Project name. Remove the redundant subtitle, not the saved data, and retain icon/name alignment.
10. **Description limit was too small (#43)** (`internal/httpapi/projects.go`). Creation and PATCH rejected descriptions above 10,000 bytes. Both now accept 15,000 Unicode characters, including subtasks, with boundary tests.
11. **Parent Tasks lacked child counts (#35)** (`internal/projects/store.go`, `web/src/projects/TasksView.svelte`). Responses and views had no subtask count. Add a scoped count to Task queries and show it in List and Board. Counting only loaded Tasks would be wrong under filters or pagination.
12. **Timer controls did not use the design system (#41)** (`web/src/app.css`). Tiny targets and undefined tokens made the timer inconsistent. Use existing surface/type tokens, static running indicators, readable elapsed time and explicit Stop & log controls, without continuous pulsing.
13. **Brand assets were incomplete (#37)** (`web/src/ui/BrandMark.svelte`, `web/public/assets/favicon.svg`). The page had no favicon; the server did not support SVG asset MIME types. Add a same-origin favicon matching the refreshed trestle geometry and test serving through the embedded production build.
14. **Settings tabs did not focus their destination** (`web/src/Settings.svelte`). Changing a section left keyboard focus on the old tab instead of the named heading. Focus the rendered heading after Svelte updates; existing browser tests cover Integration navigation.
15. **Phone task controls overflowed at enlarged text** (`web/src/app.css`, `web/src/projects/TasksView.svelte`). At 320px and 200% text, the layout switch and task action row extended beyond the viewport. Allow both groups to wrap; give normal phone header actions a readable two-column layout. Otherwise users must scroll sideways or read labels broken into individual letters.

## Verification and limits

Regression coverage lives in `internal/httpapi/audit_regression_test.go`, the existing asset tests, `web/src/auth/WorkspaceChooser.test.ts`, `web/src/lib/timer.test.ts`, and `web/e2e/audit-fixes.spec.ts`.
The browser regression covers sign-in and reload links, creation metadata, Workspace creation/editing, subtask counts, favicon serving, WCAG-tagged axe checks and reflow at 390/768/1440px in both themes, plus the active timer at 320px with 200% text. Browser tests run the production bundle through Go with API fixtures. Database regressions use an isolated PostgreSQL container; existing running service databases are untouched. The temporary container was removed after the database tests.

Not checked: exhaustive review of every source file, production infrastructure, real provider credentials/delivery, backup restoration into another instance, high-load or multi-process operation. Notification formatting is tested locally; it is not a claim of complete Markdown feature parity between chat providers. Exports remain JSON snapshots, not a new restore/import feature.

Dependency checks: `npm audit` reported no advisories. `govulncheck` reported no vulnerable imported packages or reachable symbols. Its module-only advisory GO-2026-5932 concerns the unused `golang.org/x/crypto/openpgp` package; Trestle uses the module for password hashing, not OpenPGP. No dependency change was made for that unreachable package.

Known export limit: snapshots are buffered in memory. This fix prevents silent pagination loss but does not make backups suitable for datasets larger than the server's available memory.
