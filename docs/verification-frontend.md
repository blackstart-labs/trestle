## Security and limitations

Production HTTP has a restrictive same-origin CSP, no-store and nosniff. Only
known compiled assets are routed; no filesystem lookup or HTML catch-all. Browser
failure messages are fixed and do not render raw server/network content. Vite
development is loopback-only and does not have the production header contract.
Bundled Svelte/esm-env MIT notices are generated by Vite and embedded/served with
assets; remaining full Rust release-notice inventory is still a release gate.

No database schema, configuration or health contract changes. No sessions,
authorization, workspace isolation, navigation shell or domain product workflows.
No hosted Actions, Firefox/WebKit/physical mobile, screen-reader review, complete
WCAG audit, load benchmark or platform portability claim. Playwright reports this
host OS as unsupported and uses its Ubuntu 22.04 fallback Chromium successfully.
The foundation page is not a production-readiness certificate.
